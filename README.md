# Global Tech Career

Responsive static landing page for **The International Tech Career Playbook**, with a free course preview and direct Hotmart checkout.

## Site files
- `index.html` — course landing page, search metadata, Open Graph tags, and Course structured data.
- `assets/Global_Tech_Career_Hotmart_Banner_3x1.png` — hero banner.
- `assets/Hotmart_Product_Cover_Vertical.png` — course cover shown in the hero.
- `favicon.svg` — brand mark.
- `robots.txt` and `sitemap.xml` — search crawler instructions and sitemap.

## Course structure
- Free preview: Start Here — Your International Tech Career Roadmap.
- Module 1: Career Strategy & Job Search Planning.
- Module 2: Resume & Professional Profile.
- Module 3: Interview Preparation.
- Module 4: AI-Powered Job Search Workflow.
- Eight paid lessons across the four modules.
